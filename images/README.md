## How to Contribute Images

1. Take high-quality game screenshots
2. Add descriptive filenames
3. Organize by game category
4. Submit as pull request with descriptions
5. Update this index with image details

## Screenshot Guidelines

- Resolution: 1280x720 or higher
- Clear, well-lit gameplay scenes
- Show important UI elements
- Include control overlays where relevant
- Add descriptive captions
