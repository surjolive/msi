# MSI Repository

A project repository containing MSI application configuration and player files.

## Contents

- **com.dts.freefireth.cfg** - Configuration file for the FreeFire application
- **MSI-APP-Player.zip** - MSI application player archive

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/surjolive/msi.git
cd msi
```

2. Extract the MSI-APP-Player if needed:
```bash
unzip MSI-APP-Player.zip
```

## Configuration

The `com.dts.freefireth.cfg` file contains application configuration settings. Modify as needed for your setup.
