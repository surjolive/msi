## ⚙️ Customization Options

### Sensitivity Settings

**Mouse Sensitivity X:** Control horizontal aiming speed
- Range: 0.1 - 10.0
- Default: 2.0
- Recommended: 1.5 - 3.0

**Mouse Sensitivity Y:** Control vertical aiming speed
- Range: 0.1 - 10.0
- Default: 2.0 (with Y-ratio of 0.5)
- Recommended: 1.0 - 2.0

**Gamepad Sensitivity:** Controller aiming speed
- Range: 0.5 - 2.0
- Default: 1.0
- Recommended: 0.8 - 1.5

### Advanced Options

**Mouse Acceleration:** Enable/disable acceleration
- Default: Disabled
- Impact: Affects tracking smoothness

**Deadzone Radius:** Controller stick sensitivity threshold
- Range: 0.0 - 1.0
- Default: 0.0 (Maximum sensitivity)
- Adjustment: Higher = Less sensitive

**Exclusive Mode:** Bind certain keys exclusively
- Usage: Prevents accidental key conflicts
- Delay: 200ms by default

### Multi-Key Combinations

## 📝 Tips for Optimization

### For Competitive Gaming
1. Lower sensitivity for precise aiming
2. Enable mouse acceleration for quick turns
3. Customize weapon-specific layouts
4. Practice muscle memory with consistent controls

### For Casual Gaming
1. Increase sensitivity for easier movement
2. Simplify control scheme
3. Use gamepad for comfort
4. Enable auto-aim assistance if available

### For Strategic Games
1. Prioritize map interaction (M key)
2. Quick inventory access (Tab key)
3. Efficient item management
4. Team communication setup
